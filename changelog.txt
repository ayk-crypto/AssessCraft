=== AssessCraft Changelog ===

= 0.18.1 - 2026-07-26 =

WordPress.org compliance update.

* Removes the one-published-assessment restriction from the Free edition.
* Removes the obsolete publish-limit notice and disabled Publish-button behavior.
* Updates entitlement tests and public documentation for unlimited publishing.
* Keeps Pro differentiated through advanced features rather than assessment volume.

= Pre-release history =

The 0.18.0 alpha and beta cycle established the Free/Pro entitlement model,
improved the assessment editor and template library, refined consultation
request storage and privacy controls, removed the abandoned Freemius approach,
retired the onboarding screen, and refined the Free publishing-limit user
experience. The final beta.3 package was verified on WordPress staging before
promotion to 0.18.0 stable.
