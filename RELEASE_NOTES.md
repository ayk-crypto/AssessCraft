# AssessCraft Free 0.18.0

AssessCraft Free 0.18.0 is the first stable public release of the WordPress
assessment and report builder by Onset Media.

## Highlights

- Build scored, multi-stage assessments with unlimited stages and questions.
- Configure standard score bands and up to three conditional result profiles.
- Publish with the native Gutenberg block or a shortcode.
- Generate personalized reports with interpretations and recommendations.
- Start from the bundled assessment template.
- Optionally store consultation requests in the WordPress database.
- Manage stored requests with search, filters, deletion, purge, retention,
  personal-data export, and erasure support.
- Keep additional assessments as drafts while Free permits one published
  assessment.
