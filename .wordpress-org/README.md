# WordPress.org assets

Copy the rendered files from this directory to the top-level `assets` directory
of the WordPress.org SVN repository. These files must not be included in the
installable plugin ZIP.

- `icon-128x128.png`
- `icon-256x256.png`
- `icon.svg`
- `banner-772x250.png`
- `banner-1544x500.png`
- `screenshot-1.jpg` through `screenshot-8.jpg`

The numbered screenshot descriptions are maintained in the same order under
the `Screenshots` section of the root `readme.txt`.
